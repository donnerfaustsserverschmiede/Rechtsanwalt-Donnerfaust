# Rechtsanwalt Donnerfaust – GitHub Pages

Diese Version ist vollständig statisch und benötigt weder Node.js noch PHP. Die Anwendung wird direkt in `index.html` gestartet; dadurch kann kein falscher Pfad zu `app.js` das Laden verhindern.

## GitHub Pages
Alle vier Dateien (`index.html`, `style.css`, `app.js`, `README.md`) müssen direkt im veröffentlichten Pages-Ordner liegen. Nicht die ZIP-Datei selbst veröffentlichen.

## Speicherung
Mandanten, Akten, Rechnungen, Termine, Aufgaben, Notizen usw. werden lokal im Browser gespeichert. Unter Verwaltung gibt es Daten sichern/wiederherstellen.

Nur für RP verwenden; keine echten vertraulichen Mandantendaten eintragen.
